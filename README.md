# 투자 자동매매 프로그램 (Phase 1: 데이터 수집)

## 📌 프로젝트 개요

**목표**: 여러 투자 지표가 동시에 긍정적 신호를 보일 때만 자동으로 매매하는 프로그램 구현

**현재 단계**: Phase 1 - 데이터 수집 자동화 (진행 중, 문제 있음)

**기한**: 11월 7일까지 30거래일 데이터 축적

---

## 🎯 투자 전략

### 투자 판단 규칙
모든 조건이 동시에 충족될 때만 매수 (단일 지표 기반 투자 금지)

**매수 신호**:
1. ✅ 국내 지표: 외국인/기관 순매수, 개인 심리 긍정적
2. ✅ 코스피/코스닥 상승 추세
3. ✅ 미국 시장: S&P500 상승, VIX 낮음
4. ✅ 개별 종목 기술적 신호
5. ✅ **모든 조건이 align**

**매도 신호**: 위 조건 중 2개 이상 깨질 때

---

## 📊 수집 데이터

### 1. 국내 시장
- **주가 데이터** (개별 종목)
  - OHLCV (Open, High, Low, Close, Volume)
  - 일일 수집
  - 테스트 종목: 005930, 000660, 005380, 051910, 207940

- **시장 지수**: 코스피 (KOSPI), 코스닥 (KOSDAQ)
- **시장 흐름**: 외국인/기관/개인 순매수·순매도

### 2. 해외 시장
- S&P 500, 나스닥 지수
- VIX (변동성 지수)

---

## 🛠️ 기술 사양

### 환경
- **OS**: Windows PC
- **폴더**: `C:\클로드 바이브 코딩\투자 데이터 모으기\`
- **자동화**: Windows Task Scheduler (매일 9:00 AM)

### API
- **제공자**: KIS (한국투자증권)
- **인증**: OAuth2
- **계좌**: 실전 계좌 (모의 투자 X)
- **엔드포인트**: `/uapi/domestic-stock/v1/quotations/inquire-daily-itemchartprice`

### 데이터 저장
- **형식**: CSV (utf-8-sig)
- **파일**: `투자_지표.csv`
- **컬럼**: date, code, open, close, high, low, volume
- **정책**: 매일 추가 (누적)

### 필수 환경 변수 (.env)
```
KIS_REAL_APP_KEY=your_key
KIS_REAL_APP_SECRET=your_secret
KIS_BASE_URL=https://openapi.koreainvestment.com:9443
```

## ❌ 현재 문제

### 증상
```
✅ 토큰 획득 성공
✗ 005930: 데이터 없음 (output 비어있음)  ← 모든 종목
✗ 000660: 데이터 없음 (output 비어있음)
수집 완료: 0개 데이터
```

### 분석
- ✅ 토큰 획득: 성공
- ✅ API 요청: 성공 (rt_cd="0")
- ❌ 응답 데이터: 비어있음

**원인 불명** - API 매개변수 또는 응답 구조 재검토 필요
