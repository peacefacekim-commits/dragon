# 예산 분석기 (오프라인 / 내부망용)

> 이 저장소에는 도구가 두 개 있습니다. 통장 스캔을 결의서용 표로 정리하는
> 도구는 [`passbook_ledger/README.md`](passbook_ledger/README.md) 를 보세요.

엑셀 파일을 **분석 양식**에 따라 분석해, 차트가 들어간 HTML 보고서와 엑셀 결과를 만듭니다.

> **분석 내용이 코드에 박혀 있지 않습니다.**
> "무엇을 어떻게 집계할지"는 JSON 양식 파일 하나에 적혀 있고, 프로그램은 그걸 실행만 합니다.
> 새로운 분석이 필요하면 코드를 고치는 대신 **양식을 만들거나 고치면 됩니다.**

> **인터넷이 없는 PC에서 그대로 동작합니다.**
> `pip install` 이 필요 없습니다. pandas · openpyxl · matplotlib 을 쓰지 않고
> 파이썬 표준 라이브러리만으로 엑셀 읽기/쓰기와 차트를 직접 구현했습니다.

## 필요한 것

| 항목 | 내용 |
|---|---|
| 파이썬 | 3.9 이상 (Windows 공식 설치본이면 충분) |
| 추가 패키지 | **없음** |
| 인터넷 | **불필요** |

GUI(창 모드)는 `tkinter` 를 씁니다. Windows·macOS 공식 설치본에는 기본 포함이고,
리눅스만 `python3-tk` 가 따로 필요합니다. GUI 가 없어도 명령줄은 항상 동작합니다.

## 내부망 PC로 옮기기

1. 이 폴더 전체를 USB 등으로 복사합니다.
2. 대상 PC에 파이썬이 없다면 [python.org] 설치 파일을 함께 받아가 설치합니다.
   설치 시 **"Add python.exe to PATH"** 를 체크하세요.
3. 복사한 폴더에서 아래 명령을 실행하면 끝입니다.

설치·빌드 과정이 없습니다. 폴더를 복사하는 것이 곧 설치입니다.

## 빠른 시작

```bash
# 1. 양식 없이 실행 — 컬럼을 자동 인식해 기본 양식으로 분석
python -m budget_analyzer 예산.xlsx

# 2. 그 양식을 파일로 저장
python -m budget_analyzer 예산.xlsx --save-template 우리양식.json

# 3. 우리양식.json 을 열어 원하는 대로 고친 뒤, 그 양식으로 분석
python -m budget_analyzer 예산.xlsx --template 우리양식.json
```

창 모드가 편하면 Windows에서 `실행.bat` 을 더블클릭하거나:

```bash
python -m budget_analyzer --gui
```

GUI는 세 탭으로 되어 있습니다. **1. 데이터**에서 엑셀을 열고, **2. 분석 양식**에서
블록·측정값·수식을 눈으로 보며 정의하고, **3. 실행**에서 보고서를 뽑습니다.
JSON을 직접 쓸 필요는 없습니다.

## 분석 양식

양식은 JSON 파일 하나입니다. 구조는 이렇습니다.

```
양식
├─ 시트 / 머리글행       어떤 시트의 몇 행부터 읽을지
├─ 전체필터             분석에서 제외할 행 (수식)
├─ 파생컬럼[]           원본 행 단위로 새로 만드는 컬럼 (수식)
├─ 요약[]               보고서 맨 위의 큰 숫자 타일 (수식)
└─ 블록[]               보고서 섹션 하나하나
   ├─ 유형             집계 | 추이 | 목록
   ├─ 필터             이 블록에만 적용할 조건
   ├─ 기준[]           묶는 기준 컬럼 (여러 개 = 교차 집계)
   ├─ 측정값[]         합계·평균·건수·고유건수·최대·최소·중앙값
   ├─ 계산[]           집계 결과 위에서 다시 계산할 컬럼 (수식)
   ├─ 정렬 / 상위 / 차트
   └─ 규칙[]           조건에 걸리면 경고 문구를 띄움 (수식)
```

가장 작은 양식은 이 정도입니다.

```json
{
  "이름": "부서별 집행 현황",
  "블록": [
    {
      "이름": "부서별 집계",
      "기준": ["부서"],
      "측정값": [{ "컬럼": "집행액", "함수": "합계", "서식": "금액" }],
      "계산": [{ "이름": "구성비", "식": "비율([집행액])", "서식": "비율" }],
      "정렬": "집행액",
      "차트": "막대"
    }
  ]
}
```

`samples/양식_예시.json` 에 필터·파생컬럼·사용자 정의 판정 기준·교차 집계·원본 목록을
모두 쓴 예시가 들어 있습니다. 복사해서 고쳐 쓰기 좋은 출발점입니다.

### 수식

컬럼은 `[컬럼명]` 처럼 대괄호로 감쌉니다. 계산은 열 단위로 이뤄지고,
`합계(...)` 처럼 값 하나가 되는 함수는 필요한 자리에서 자동으로 모든 행에 퍼집니다.
그래서 `[집행액] / 합계([집행액])` 이 그대로 구성비가 됩니다.

| 종류 | 함수 |
|---|---|
| 행마다 | `조건(조건식, 참값, 거짓값)` `절대값` `반올림` `포함` `비어있음` |
| 열 → 값 하나 | `합계` `평균` `중앙값` `건수` `고유건수` `최대` `최소` |
| 열 → 열 | `누적` `비율` `누적비율` `증감률` `순위` |

연산자는 `+ - * / % **`, `== != < <= > >=`, `and or not`, `& |` 를 씁니다.
문자열은 큰따옴표로 감쌉니다. (`ABS`, `SUM`, `IF` 같은 영문 이름도 받습니다.)

자주 쓰는 조합:

| 하고 싶은 것 | 수식 |
|---|---|
| 구성비 | `비율([집행액])` |
| 누적 구성비 | `누적비율([집행액])` |
| 집행률 | `[집행액] / [예산액]` |
| 잔액 | `[예산액] - [집행액]` |
| 전기 대비 증감률 | `증감률([집행액])` |
| 3단계 판정 | `조건([집행률] > 1, "초과", 조건([집행률] < 0.7, "부진", "정상"))` |
| 특정 사업만 | `포함([사업명], "지원")` |
| 상반기만 | `[집행일자] < "2026-07-01"` |

전체 목록은 `python -m budget_analyzer --함수목록` 또는 GUI의 **함수 도움말** 버튼에서 볼 수 있습니다.

수식은 `eval` 로 실행하지 않습니다. `ast` 로 파싱해 허용한 노드만 직접 계산하므로,
양식에 무엇이 적혀 있어도 파일·네트워크·임의 코드에 접근할 수 없습니다.

### 서식

`측정값`·`계산`·`요약` 에 `서식` 을 지정하면 표시 방법이 정해집니다.

| 서식 | 결과 |
|---|---|
| `금액` | `1,234,567` (우측 정렬, 표 합계에 포함) |
| `비율` | `92.1%` (합계에서 제외) |
| `정수` / `소수` | 자릿수 지정 |
| `상태` | 색깔 배지. `초과·위험`은 빨강, `부진·주의`는 노랑, `정상·양호`는 초록 |
| `문자` | 그대로 |
| `자동` | 컬럼 이름을 보고 알아서 |

표의 합계 행은 **합산이 말이 되는 컬럼만** 더합니다. 평균·비율·상태는 비워 둡니다.

## 명령줄 옵션

```bash
python -m budget_analyzer 예산.xlsx --sheet 집행내역        # 시트 지정
python -m budget_analyzer 예산.xlsx --header-row 3          # 머리글 행 지정
python -m budget_analyzer 예산.xlsx --list-sheets           # 시트 목록만
python -m budget_analyzer 예산.xlsx --예시양식               # 만들어 볼 수 있는 예시 양식 목록
python -m budget_analyzer 예산.xlsx --예시 2                # 예시 양식으로 실행
python -m budget_analyzer 예산.xlsx --check-template 양식.json  # 양식이 이 파일에 맞는지 검사
python -m budget_analyzer 예산.xlsx --xlsx 결과.xlsx --csv-dir ./csv  # 엑셀·CSV 내보내기
python -m budget_analyzer --함수목록                         # 수식 함수 목록
```

`--category` / `--budget` / `--actual` / `--date` 로 컬럼 자동 인식을 바로잡을 수 있고,
`--save-profile` / `--profile` 로 그 매핑을 저장해 재사용할 수 있습니다.
전체 옵션은 `python -m budget_analyzer --help`.

### 파이썬 코드에서

```python
from budget_analyzer import read_table, load_template, run, write_report

table = read_table("예산.xlsx", sheet="집행내역")
보고서 = run(table, load_template("우리양식.json"), source="예산.xlsx")

print(보고서.tiles)          # 요약 타일
print(보고서.blocks[0].표)    # 첫 블록의 결과 표
write_report("보고서.html", 보고서)
```

## 어떤 엑셀이든 받아주려고 한 것들

- **머리글이 1행이 아닌 경우** — 위에 제목 줄·빈 줄이 있어도 실제 머리글 행을 찾습니다
- **문자열로 들어간 금액** — `"1,234,567"`, `"1,200,000원"`, `"(1,200)"`(회계식 음수), `"12.5%"`
- **날짜 표기 혼재** — 엑셀 날짜 셀, `2026-03-09`, `2026.3.9`, `2026년 3월 9일`, `20260309`
- **한글 CSV** — `cp949`/`euc-kr` 로 저장된 파일도 자동 판별
- **중복·빈 머리글** — `금액`, `금액_1`, `컬럼5` 처럼 살려 씁니다
- **시트가 여러 개** — 지정하지 않으면 내용이 가장 많은 시트를 고릅니다

**컬럼 자동 인식**은 양식을 처음 만들 때의 출발점을 잡아주는 용도입니다. 머리글 이름과
값의 성격(숫자 비율, 반복도, 자릿수)을 함께 보고 추정하며, `사업코드`·`연번` 처럼
숫자지만 금액이 아닌 컬럼은 제외합니다. **추정 결과는 반드시 확인하세요.** 보고서 머리말과
GUI 미리보기에 항상 표시됩니다.

## 오류를 만났을 때

양식의 한 부분이 잘못돼도 전체가 멈추지 않습니다. 문제가 있는 블록·수식만 건너뛰고
나머지는 그대로 진행하며, 무엇이 왜 빠졌는지 보고서 맨 아래 **"확인이 필요한 사항"** 에 남습니다.
실행 전에 미리 확인하려면 `--check-template` 또는 GUI의 **양식 검사** 버튼을 쓰세요.

## 구조

```
budget_analyzer/
  table.py         경량 표 자료구조 (pandas 대체) — 값 파싱, 그룹 집계, 정렬
  xlsx_reader.py   zipfile + xml.etree 로 xlsx/csv 읽기
  xlsx_writer.py   최소 스펙 xlsx 쓰기 (숫자·퍼센트·날짜 서식, 자동 필터, 틀 고정)
  expression.py    사용자 수식 파서/계산기 (ast 기반, eval 미사용)
  template.py      분석 양식의 자료구조·검증·JSON 입출력·기본 양식
  engine.py        양식 실행 — 필터·집계·계산·규칙
  mapping.py       컬럼 역할 자동 인식 (양식 자동 생성의 출발점)
  charts.py        SVG 차트 직접 생성 (matplotlib 대체)
  report.py        자기완결형 HTML 보고서 (블록을 그대로 렌더링)
  cli.py           명령줄 인터페이스
  gui.py           tkinter 창 인터페이스 (양식 편집기 포함)
samples/
  make_sample.py   시연·테스트용 예산 엑셀 생성기
  양식_예시.json    직접 만든 양식 예시
tests/
  test_budget_analyzer.py
```

## 개발

```bash
python samples/make_sample.py                              # 샘플 엑셀 생성
python -m budget_analyzer samples/예산_샘플.xlsx             # 기본 양식으로
python -m budget_analyzer samples/예산_샘플.xlsx -t samples/양식_예시.json
python -m unittest discover -s tests -v                    # 테스트 (90개)
```

## 알려진 제한

- **`.xls` (구형 바이너리) 는 읽지 못합니다.** 엑셀에서 `.xlsx` 로 다시 저장해 주세요.
- 수식이 든 셀은 **엑셀이 마지막으로 계산해 저장한 값**을 읽습니다. 다른 도구로 만든
  파일이라면 엑셀에서 한 번 열어 저장하세요.
- 병합된 셀은 좌상단 값만 인식합니다.
- 매우 큰 파일(수십만 행)은 메모리에 전부 올리므로 느려질 수 있습니다.
- 차트는 블록당 상위 15개 항목까지 그립니다. 전체 값은 표와 엑셀 내보내기에 있습니다.
- **GUI는 개발 환경에 tkinter가 없어 실행 테스트를 하지 못했습니다.** 분석 엔진·CLI·
  보고서는 모두 검증했습니다. Windows에서 문제가 있으면 알려주세요.
