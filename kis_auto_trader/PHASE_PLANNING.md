## 📅 Phase 1: 데이터 수집 단계 (Collection Phase)

**기간**: 30-50일 (1.5~2.5개월)  
**목표**: 충분한 신호 데이터 수집

### 일일 작업 (09:35 실행)

```bash
python collect_paper_signals.py

# 출력:
# - 어제 신호 판정 (약세/강세)
# - OVN 계산
# - 예측 수익률
# - 실제 수익률 (다음 날 데이터 있으면)
# - data/paper_signals.csv 업데이트
```

### 수집 데이터

| 항목 | 설명 | 용도 |
|------|------|------|
| 날짜 | 거래일 | 추적 |
| 어제 신호 | Bearish/Bullish | 신호 판정 |
| OVN | 오버나이트 수익률 | 신호 강도 |
| 예측 수익률 | 모델 예측값 | 검증 대상 |
| 실제 수익률 | 당일 수익률 | 검증 데이터 |
| 신뢰도 | 예측 신뢰도 | 신뢰도 분석 |

### 진행 상황 추적

```
1주차: 5개 데이터 포인트
2주차: 10개 포인트
3주차: 15개 포인트
...
6주차+: 30개 이상 (검증 시작)
```

**체크리스트:**
- [ ] 매일 collect_paper_signals.py 실행
- [ ] paper_signals.csv 누적 중

## 🔍 Phase 2: 상관성 검증 단계 (Validation Phase)

**시작**: 데이터 30개 모은 후  
**목표**: 예측값 vs 실제값 상관성 확인

### 주단위 검증 (주 1회, 예: 금요일)

```bash
python validate_correlation.py

# 분석 항목:
# 1. 피어슨 상관계수 (r)
# 2. 스피어만 순위 상관
# 3. p-value (통계적 유의성)
# 4. R² (설명력)
# 5. 신호별 분석 (약세 vs 강세)
```

### 검증 기준

| 체크 항목 | 기준 | 의미 |
|---------|------|------|
| **데이터 수** | 30개 이상 | 통계적 신뢰도 충분 |
| **상관계수** | \|r\| ≥ 0.3 | 적어도 약한 상관 |
| **p-value** | < 0.05 | 통계적으로 유의미 |
| **R²** | > 0.09 (r²) | 설명력 9% 이상 |

### 판정 결과

```
✅ READY (모든 기준 충족)
   → Phase 3로 진행 (실거래 시작)

🟡 MONITOR (2-3개 기준 충족)
   → Phase 1 계속 (데이터 추가 수집)

🔴 NOT_READY (1개 이하 충족)
   → 전략 재검토 필요
```

### 예상 결과 (백테스트 기반)

```
약세 신호 + 음수 OVN:
  - 예측 수익률: +0.592%
  - 실제 수익률: +0.5% ~ +0.7% (기대)
  - 상관계수: r ≈ 0.5 (강한 양의 상관)
  - 승률: 80% 이상
```
