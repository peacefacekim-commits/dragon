# 표본 - 우리가 가진 증거가 실제로 얼마나 되나

(2026-09-22 신설) 사용자 지적 둘에서 시작했다.

> "이 데이터가 못 믿음직스러운 게 반복된 게 아니라는 거야. 당연히 길게
> 보면 표본이 적으니까 승리할 확률이 높게 보이겠지"

> "20년 30년 기다리면 그 동안 변화가 더 크겠지. 표본으로는 의미가 없어"

**둘 다 맞다.** 이 문서는 그 지적을 숫자로 옮기고, 그래서 판단 기준을
어떻게 바꿔야 하는지 적는다.

---

## 1. 내가 부풀린 숫자

"200만원으로 1년에 목표(+360,000원) 달성할 확률" 을 묻길래 이렇게 냈다.

```
시작일 182개 (5거래일 간격), 1년 안에 도달 115/182 = 63%
도달까지 중앙 118일
```

**이 63% 는 부풀려진 숫자다.**

```
내가 쓴 표본        1년 창 182개 (5거래일 간격)
실제 독립 표본      4.7개  = 사실상 5개
겹침                5일 간격 창끼리 98% 가 같은 날
```

182개처럼 보이지만 **같은 5년을 182번 다시 센 것**이다. 창을 촘촘히
자르면 표본 수는 늘어나지만 정보는 하나도 안 늘어난다.

같은 계산을 다른 곳에도 했다.

```
1년 창          독립 4.7개
120일 교체 회차  독립 9개
시작일 5개       서로 37일 차이 -> 같은 해를 다섯 번 봄
```

## 2. 정직한 표본은 연도 5개다

```
2022   -6.8%
2023  +20.5%
2024  +15.8%
2025  +58.3%
2026  +29.7%
       양수 4/5
```

**동전을 5번 던져 4번 이상 앞면이 나올 확률이 19% 다.** 실력이 전혀
없어도 다섯 중 넷은 흔하다. 4/5 는 우연으로 배제되지 않는다.

그리고 **2025년 하나가 절반을 만든다.**

```
기하평균            21.7%
2025년 빼면         14.0%
2022년 빼면         30.1%
```

## 3. 무엇이 단단하고 무엇이 약한가 (이 구분이 핵심)

지금까지 "저변동" 을 한 덩어리로 말해왔는데, 실은 두 개의 다른 주장이고
증거의 양이 전혀 다르다.

### 비교적 단단하다 — "저변동이 고변동보다 낫다"

표본이 다르다. 1,813종목 x 1,402일의 **단면** 비교이고 해마다 따로
확인된다.

```
고변동 120일   연 -41.5%
저변동 120일   연 +22.3%
              격차 63.7%p
```

이 격차는 연도 5개에 기댄 게 아니다. 매년, 거의 모든 종목에서 같은
방향이 나온다. 저변동 이상현상은 다른 나라에서도 반복 확인된 것이라
우리 5년이 유일한 근거도 아니다.

### 약하다 — "저변동이 연 22% 를 번다"

이건 **연도 5개에 전부 기대고 있고, 그중 하나가 절반을 만든다.**
한국 시장의 특정 시기 5년이다.

그런데 나는 이 22.3% 로 "Pro 구독료 된다, 여유 5.5%p" 를 여러 번
말했다. **그 근거가 5개 관측이라는 걸 제대로 말하지 않았다.**

## 4. 내가 한 실수 - 이긴 것에 잣대를 느슨하게 댔다

이번 주에 진 가설들에는 이 잣대를 계속 들이댔다.

```
"시작일 5개가 서로 겹친다"
"반띵 후반부에만 우위가 있다"
"최고 해를 빼면 남는 게 있나"
"독립 표본은 회차/보유일이다"
```

**그런데 살아남은 저변동에는 같은 잣대를 안 댔다.** 이긴 것에 더
엄격해야 하는데 반대로 했다. 진 것은 여러 번 의심하고 이긴 것은 한 번도
같은 강도로 의심하지 않았다.

사용자가 찾아냈다. 내가 찾았어야 했다.

## 5. 20~30년을 기다려도 안 풀린다

통계적으로 확실해지려면 독립 관측 20~30개, 즉 20~30년이 필요하다.
그런데 그동안 시장이 더 크게 바뀐다.

```
2002년 한국 시장과 2026년 한국 시장은 다른 시장이다.
   상장 종목, 거래 제도, 수수료, 세금, 참여자 구성, 외국인 비중,
   파생상품, 알고리즘 매매 비중이 전부 다르다.
```

**즉 표본을 늘리는 동안 재는 대상이 바뀐다.** 이건 시간이 해결하는
종류의 불확실성이 아니다. 1년을 더 기다리면 관측이 6개가 되는데 5개나
6개나 판정은 달라지지 않고, 20년을 기다리면 그때는 다른 시장이다.

**그래서 결론: 이 질문은 원리적으로 확실해지지 않는다.**

## 6. 그러면 판단 기준을 바꿔야 한다

확실해질 수 없다면 "확실해지면 한다" 는 영원히 안 하겠다는 말이거나,
아니면 확실하지도 않은데 확실한 척하고 하겠다는 말이 된다. 둘 다 틀렸다.

**확률로 결정하는 대신 손실 한도로 결정한다.**

```
틀렸을 때 얼마나 다치나  <- 이걸로 결정한다
맞을 확률이 얼마인가      <- 이건 알 수 없다
```

구체적으로는 이렇게 갈린다.

```
22.3% 를 믿으면   필요 자본 150만원
14.0% 를 믿으면   필요 자본 240만원
아예 못 믿으면     0원 (안 한다)
```

**같은 전략인데 무엇을 믿느냐로 자본이 1.6배 차이난다.** 그리고 어느
쪽이 맞는지는 알 수 없다. 그래서 **보수적인 쪽(14.0%)을 기본으로 쓰고,
그 가정에서도 목표가 나오게 자본을 잡는 것**이 맞다.

이건 이 저장소의 전제와도 맞는다 - "큰 이득을 포기하더라도 큰 손해를
피하고 작은 이득을 쌓아간다".

## 7. 이 문서가 바꾸는 것

1. **연 22.3% 를 계획 숫자로 쓰지 않는다.** 14.0% 를 쓴다.
   (analyze_goal.py 에 이 경고를 붙였다)

2. **"확률 몇 %" 같은 숫자를 겹치는 창으로 만들지 않는다.**
   내려면 독립 표본 수를 항상 같이 적는다.

3. **이긴 가설에도 진 가설과 같은 강도로 의심한다.**
   특히 표본 독립성은 이긴 쪽에서 더 크게 문제가 된다 - 진 것은
   표본이 적어도 지는 게 확실하지만, 이긴 것은 표본이 적으면 우연과
   구별이 안 되기 때문이다.

4. **"더 재면 알 수 있다" 는 말을 함부로 하지 않는다.**
   더 재도 안 되는 것이 있고, 이게 그중 하나다.

## 8. 그래도 남는 것

이 문서가 "저변동도 믿을 수 없다" 는 뜻은 아니다. 갈라서 말하면

```
저변동 > 고변동          증거 많음.  이건 믿어도 된다
저변동 = 연 22%          증거 5개.   이건 믿으면 안 된다
저변동 = 연 14% 쯤        보수적 가정. 이걸로 계획한다
저변동 > 시장(-7.0%)     증거 많음.  이것도 믿어도 된다
```

**"시장보다 낫다" 와 "연 몇 % 를 번다" 는 다른 주장이고, 앞쪽만 단단하다.**
