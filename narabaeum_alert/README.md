# 나라배움터 수강완료 알림 (모바일 웹앱)

나라배움터(또는 비슷한 이러닝) 화면의 "총 학습시간"을 사진으로 찍으면
글자를 인식해서 남은 시간을 계산하고, 다 되면 휴대폰으로 알려주는
모바일 웹앱(PWA)입니다.

- 사진은 **휴대폰 안에서만 처리**되고 서버로 전송되지 않습니다.
- 설치형 앱스토어 앱이 아니라, 브라우저에서 열어 **"홈 화면에 추가"**
  하면 아이콘이 생기고 앱처럼 실행됩니다.
- 내부망/외부망 통신 문제와는 무관합니다. 교육을 듣는 휴대폰(또는 그
  교육 화면을 찍은 사진) 안에서 완결되는 앱입니다.

## 사용 순서

1. 나라배움터에서 교육을 재생하고, 총 학습시간(또는 남은 시간)이 보이는
   화면을 이 앱의 **"사진으로 시간 인식"** 버튼으로 촬영합니다.
2. 인식된 시간 후보 중 맞는 걸 고르거나, "직접 입력"으로 시/분을
   수정합니다.
3. **"타이머 시작"**을 누르면 지금 시각부터 그 시간이 지나면 알림이
   오도록 등록됩니다.
4. 여러 과정을 동시에 들으면 타이머를 여러 개 추가할 수 있습니다.

## 호스팅 방법 (예: GitHub Pages)

카메라 촬영과 알림 기능은 브라우저 보안 정책상 `https://` (또는
`localhost`) 환경에서만 동작합니다. 이 저장소를 GitHub Pages로 배포하면
가장 간단합니다.

1. GitHub 저장소 Settings → Pages → Source에서 배포 브랜치와
   `/narabaeum_alert` 폴더(또는 루트)를 지정합니다.
2. 배포된 주소(`https://내아이디.github.io/저장소/narabaeum_alert/`)를
   휴대폰 브라우저로 열고, 공유 메뉴에서 **"홈 화면에 추가"**를 합니다.

인터넷 없이 로컬에서만 써보고 싶다면 이 폴더에서
`python -m http.server 8000` 실행 후 같은 와이파이의 휴대폰에서
`http://PC의사설IP:8000` 으로 접속해도 됩니다. (단, 카메라/알림
권한은 iOS Safari 등 일부 브라우저에서 `http://`로는 막힐 수 있어
가급적 HTTPS 배포를 권장합니다.)

## 알려진 제한

- **글자 인식이 항상 정확하지는 않습니다.** 시작 전에 인식된 시간을
  꼭 눈으로 확인하세요. 여러 후보가 뜨면 맞는 걸 고르고, 이상하면
  "직접 입력"으로 넣으세요.
- **브라우저/앱을 완전히 종료하면 알림이 늦게 오거나 안 올 수
  있습니다.** iOS/Android 모두 배터리 절약을 위해 백그라운드 타이머를
  제한하는 정책이 있어서, 순수 웹앱으로는 100% 보장할 수 없습니다.
  - 학습 중에는 앱을 완전히 끄지 말고 백그라운드로만 두는 걸
    권장합니다.
  - 앱을 다시 열면 그 시점에 이미 끝난 타이머는 즉시 "완료"로
    표시되니, 예정 시간쯤 한 번씩 열어 확인하는 것도 안전한
    방법입니다.
- 처음 사진 인식 시 글자 인식 엔진(Tesseract.js)을 CDN에서
  내려받기 때문에 **최초 1회는 인터넷 연결이 필요**합니다. 이후에는
  캐시되어 오프라인에서도 동작합니다.
- 타이머 정보는 이 휴대폰의 브라우저 저장소(localStorage)에만
  저장됩니다. 브라우저 데이터를 지우면 함께 사라집니다.

## 파일 구성

```
narabaeum_alert/
  index.html        화면 구조
  style.css         스타일
  app.js            OCR 인식, 타이머, 알림 로직
  manifest.json     PWA 설치 설정
  service-worker.js 오프라인 캐시 + 알림 클릭 처리
  icons/icon.svg    앱 아이콘
```
