# 통장 정리 도구 (오프라인 / 내부망용)

세입세출외현금 통장을 스캔한 이미지에서 거래 내역(거래일자·적요·금액·구분)을
자동으로 읽어 표로 정리하고, 그 표를 **수입결의서 / 지급결의서 hwp 양식**에
한글(HWP)의 편지 병합(메일 머지) 기능으로 밀어 넣어 거래 건별 결의서 파일을
만드는 데 쓰는 도구입니다.

> **이 도구가 hwp 파일을 직접 만들지는 않습니다.**
> hwp는 공개되지 않은 이진 포맷이라 코드로 직접 만들면 결의서 서식이 깨질 위험이
> 있습니다. 대신 한글이 원래 갖고 있는 메일 머지 기능을 쓰기 때문에, 서식은
> 한글이 그대로 만들어 절대 깨지지 않습니다. 이 도구는 메일 머지에 넣을 표를
> 만드는 부분만 자동화합니다.

> **완전히 오프라인(내부망) PC에서 동작합니다.**
> pip install 이 필요 없습니다. 서버는 파이썬 표준 라이브러리만 씁니다.
> 다만 스캔 이미지에서 글자를 읽는 OCR 엔진(Tesseract)은 한 번은 설치해야 합니다.

---

## 준비물

| 항목 | 내용 |
|---|---|
| 파이썬 | 3.10 이상 |
| Tesseract OCR | 한국어(kor) 데이터 포함, 자동 인식에 필요 (없어도 표는 직접 입력 가능) |
| 인터넷 | 실행할 때는 불필요 (설치할 때 한 번만 필요) |

### Tesseract OCR 설치 (한 번만)

내부망 PC에는 인터넷이 없으므로, **인터넷이 되는 PC에서 설치 파일을 미리 받아
USB로 옮겨 설치**합니다.

1. 인터넷이 되는 PC에서 Tesseract OCR (Windows용, "UB Mannheim" 배포판) 설치 파일을 받습니다.
2. 설치 중 **"Additional language data" 에서 Korean(한국어)** 을 반드시 선택합니다.
3. 설치 파일을 USB로 내부망 PC에 옮겨 실행합니다. 설치 시 **"Add to PATH"** 옵션을 체크하면
   명령 프롬프트에서 `tesseract --version` 이 바로 동작합니다.
4. 설치가 끝나면 이후로는 인터넷 없이 계속 씁니다.

Tesseract를 설치하지 않아도 이 도구는 실행됩니다. 다만 자동 인식 없이 표를
직접 입력해야 합니다.

## 빠른 시작

```bash
python -m passbook_ledger
```

브라우저가 자동으로 열립니다 (안 열리면 `http://127.0.0.1:8877/` 로 직접 접속).
Windows에서는 `실행.bat` 을 더블클릭해도 됩니다.

1. 통장 스캔 이미지를 올리고 **인식하기**를 누릅니다.
2. 자동으로 채워진 표에서 **노란 줄(확인 필요)** 을 스캔본과 대조해 고칩니다.
   거래일자·적요·금액·잔액이 확실하지 않으면 일부러 빈 칸으로 남겨 둡니다.
3. 통장에 없는 정보(납부자/수령인, 관/항/목, 비고)는 직접 채웁니다.
4. 다 채웠으면 **표 복사(클립보드)** 로 엑셀/한글 표에 바로 붙여넣거나,
   **CSV로 저장**해 파일로 둡니다.

```bash
python -m passbook_ledger --port 9000      # 포트 지정
python -m passbook_ledger --no-browser     # 브라우저 자동 실행 안 함
```

## 결의서 hwp에 자동으로 채워 넣기 (한글 메일 머지)

한글(HWP)에 내장된 **편지 병합(메일 머지)** 기능을 한 번만 설정해 두면,
거래 건수만큼 결의서 hwp 파일이 자동으로 만들어집니다.

1. `수입결의서.hwp` / `지급결의서.hwp` 양식을 한글에서 엽니다.
2. 값이 들어갈 자리마다 **입력 → 필드 입력 → 누름틀**(또는 `도구 → 편지 병합 →
   필드 만들기`)로 필드를 넣습니다. 필드 이름은 이 도구가 만든 표의 열 이름과
   **똑같이** 맞춥니다: `거래일자`, `적요`, `구분`, `금액`, `잔액`, `메모`,
   `납부자/수령인`, `관`, `항`, `목`, `비고`.
3. 양식을 저장합니다.
4. `도구 → 편지 병합 → 편지 병합 실행` 에서 **자료 파일**로 이 도구에서 저장한
   `통장정리.csv` 를 선택합니다 (인코딩은 UTF-8).
5. 출력 방향을 **파일로 저장**으로 두면, 거래 건마다 결의서 hwp 파일이 하나씩
   만들어집니다. 수입/지급이 섞여 있다면 표의 **구분** 열로 정렬해 수입 건은
   수입결의서 양식으로, 지급 건은 지급결의서 양식으로 각각 병합하면 됩니다.

## 인식이 잘 안 될 때

- 스캔 해상도가 낮거나 기울어진 경우 인식률이 떨어집니다. 가능하면 200dpi
  이상, 반듯하게 스캔하세요.
- "CD입금/CD지급"처럼 한글과 영문이 붙어 있는 표현은 OCR이 자주 틀립니다.
  이런 흔한 표현은 자동으로 표준 표기로 보정하고 확인 표시를 남기지만,
  사전에 없는 표현은 원문 그대로 두니 스캔본과 대조해 확인하세요.
- 출금/입금 금액이 모두 인식되면(칸을 잘못 나눈 경우) **구분**을 비워 두고
  "확인필요"로 표시합니다. 표에서 직접 지급/수입 중 하나를 골라 채우세요.
- 잔액처럼 신뢰도가 낮게 인식된 칸은 값을 억지로 채우지 않고 비워 둡니다.
  틀린 값을 자동으로 넣는 것보다 빈 칸으로 두는 쪽이 안전하다고 판단했습니다.

## 구조

```
passbook_ledger/
  ocr.py       tesseract 실행 + TSV(단어 좌표) 파싱 → 표 구조 복원 (표준 라이브러리만 사용)
  server.py    표준 라이브러리 http.server 기반 로컬 서버, POST /api/ocr
  __main__.py  실행 진입점 (python -m passbook_ledger)
  static/
    index.html 업로드 · 편집 표 · 복사/CSV 내보내기 (외부 라이브러리 없는 순수 HTML/JS)
```

## 알려진 제한

- Tesseract 없이 실행하면 자동 인식 없이 표만 직접 입력할 수 있습니다.
- 손글씨나 도장이 겹친 글자는 인식하지 못할 수 있습니다.
- 한 이미지에 여러 페이지 표가 붙어 있으면 줄 구분이 흐트러질 수 있으니,
  가능하면 통장 한 면씩 스캔하세요.
