# 웹페이지 뒤집기 (개발자 도구용)

브라우저 개발자 도구(콘솔)에 붙여넣으면 현재 보고 있는 웹페이지를 통째로
180도 회전시켜 거꾸로 보여주는 아주 작은 도구입니다.

> **인터넷 연결이 없는 내부망(인트라넷) 페이지에서도 그대로 동작합니다.**
> CDN이나 외부 이미지·폰트 등을 전혀 불러오지 않는 순수 자바스크립트이며,
> 지금 열려 있는 탭 안에서만 실행되는 임시 효과입니다(새로고침하면 사라짐).

---

## 사용법 1 — 콘솔에 붙여넣기 (가장 간단)

1. 뒤집고 싶은 페이지에서 개발자 도구를 엽니다.
   - Windows/Linux: `F12` 또는 `Ctrl` + `Shift` + `I`
   - macOS: `Cmd` + `Option` + `I`
2. **Console(콘솔)** 탭을 클릭합니다.
3. [`flip.console.js`](./flip.console.js) 파일 내용을 전부 복사해 콘솔에 붙여넣고 `Enter`.
4. 페이지가 거꾸로 뒤집힙니다. **같은 코드를 한 번 더 실행하면 원래대로 돌아옵니다.**

> 콘솔에 코드를 처음 붙여넣으면 브라우저가
> "코드를 붙여넣으면 안 됩니다"류의 경고를 보여줄 수 있습니다. 직접 입력한 것이
> 맞다면 안내대로 `allow pasting` 등을 입력해 진행하면 됩니다.

## 사용법 2 — 즐겨찾기(북마클릿)로 등록해 한 번 클릭으로 실행

매번 콘솔을 열기 번거롭다면 북마크바에 버튼으로 등록해 둘 수 있습니다.

1. 새 즐겨찾기를 하나 만듭니다. (이름은 예: `페이지 뒤집기`)
2. 주소(URL) 칸에 [`flip.bookmarklet.txt`](./flip.bookmarklet.txt) 파일의 내용을
   그대로 복사해 붙여넣고 저장합니다. (`javascript:`로 시작하는 한 줄짜리 코드입니다.)
3. 뒤집고 싶은 페이지에서 방금 만든 즐겨찾기를 클릭하면 바로 뒤집힙니다.
   다시 클릭하면 원래대로 돌아옵니다.

북마클릿도 콘솔 스크립트와 똑같이 외부 요청이 전혀 없는 코드이므로
사내 시스템, 사설 인트라넷 사이트 등 인터넷이 막힌 환경에서도 동일하게 동작합니다.

---

## 동작 원리

`<html>` 요소에 `transform: rotate(180deg)`를 적용하는 `<style>` 태그 하나를
페이지에 삽입/제거하는 것이 전부입니다. 페이지의 실제 내용, 서버로 보내는 요청,
저장된 데이터는 전혀 건드리지 않으며, 탭을 새로고침하거나 닫으면 효과는 사라집니다.

일부 사이트는 보안 정책(CSP)으로 인해 콘솔에서 실행한 스크립트의 동작이
제한될 수 있습니다. 이 도구는 순수 CSS 스타일 삽입만 사용하므로 대부분의
내부망 페이지에서 문제없이 동작하지만, 아주 엄격한 CSP를 쓰는 사이트에서는
스타일 삽입 자체가 막힐 수 있습니다.
