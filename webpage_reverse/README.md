# 웹페이지 코드로 보기 (개발자 도구용)

브라우저 개발자 도구(콘솔)에 붙여넣으면, 지금 화면에 "실제로 그려져 있는" 페이지를
사람이 읽기 좋은 HTML 코드로 정리해 새 탭에 보여주는 도구입니다.

- 브라우저의 **페이지 소스 보기(`Ctrl+U`)** 는 서버가 맨 처음 내려준 원본 HTML만
  보여줍니다. 자바스크립트가 나중에 만들어 붙인 내용은 나오지 않습니다.
- 이 도구는 그 대신 **지금 이 순간의 DOM**(자바스크립트로 추가/변경된 내용까지 전부)을
  가져와 들여쓰기를 붙여 정리하고, 복사·다운로드 버튼과 함께 보여줍니다.

> **인터넷 연결이 없는 내부망(인트라넷) 페이지에서도 그대로 동작합니다.**
> 외부 서버로 아무것도 전송하지 않고, CDN 등 외부 리소스도 전혀 불러오지 않는
> 순수 자바스크립트이며, 지금 열려 있는 탭 안에서만 동작합니다.

---

## 사용법 1 — 콘솔에 붙여넣기 (가장 간단)

1. 코드로 보고 싶은 페이지에서 개발자 도구를 엽니다.
   - Windows/Linux: `F12` 또는 `Ctrl` + `Shift` + `I`
   - macOS: `Cmd` + `Option` + `I`
2. **Console(콘솔)** 탭을 클릭합니다.
3. [`view_source.console.js`](./view_source.console.js) 파일 내용을 전부 복사해
   콘솔에 붙여넣고 `Enter`.
4. 정리된 HTML 코드가 담긴 새 탭이 열립니다. 상단의 **코드 복사** / **.html로 다운로드**
   버튼으로 결과를 바로 복사하거나 파일로 저장할 수 있습니다.

> 콘솔에 코드를 처음 붙여넣으면 브라우저가
> "코드를 붙여넣으면 안 됩니다"류의 경고를 보여줄 수 있습니다. 직접 입력한 것이
> 맞다면 안내대로 `allow pasting` 등을 입력해 진행하면 됩니다.
> 새 탭이 열리지 않으면 주소창 오른쪽에 뜨는 **팝업 차단** 알림에서 허용해 주세요.

## 사용법 2 — 즐겨찾기(북마클릿)로 등록해 한 번 클릭으로 실행

1. 새 즐겨찾기를 하나 만듭니다. (이름은 예: `코드로 보기`)
2. 주소(URL) 칸에 [`view_source.bookmarklet.txt`](./view_source.bookmarklet.txt) 파일의
   내용을 그대로 복사해 붙여넣고 저장합니다. (`javascript:`로 시작하는 한 줄짜리 코드입니다.)
3. 코드로 보고 싶은 페이지에서 방금 만든 즐겨찾기를 클릭하면 바로 새 탭이 열립니다.

북마클릿도 콘솔 스크립트와 완전히 같은 코드이며 외부 요청이 전혀 없으므로
사내 시스템, 사설 인트라넷 사이트 등 인터넷이 막힌 환경에서도 동일하게 동작합니다.

---

## 동작 원리

1. `document.documentElement.outerHTML` 로 현재 DOM 전체를 문자열로 가져옵니다.
2. 태그 단위로 잘라 들여쓰기를 붙이는 자체 포매터로 읽기 좋게 정리합니다.
   `<script>`/`<style>` 내용은 태그로 잘못 인식하지 않도록 통째로 다룹니다.
3. 결과를 HTML로 이스케이프한 뒤 `Blob` + `URL.createObjectURL` 로 새 탭에 표시합니다.
   서버에 아무것도 요청하지 않고 브라우저 메모리 안에서만 처리합니다.

일부 사이트는 보안 정책(CSP)으로 콘솔 스크립트의 동작을 제한할 수 있습니다.
이 도구는 새 창 열기(`window.open`)와 `Blob` URL만 사용하므로 대부분의 내부망
페이지에서 문제없이 동작하지만, 팝업을 강하게 차단하는 브라우저 설정에서는
새 탭이 열리지 않을 수 있습니다(위 팝업 차단 알림 참고).

## 파일 구성

```
webpage_reverse/
  view_source.console.js       콘솔에 붙여넣는 원본 스크립트 (읽기 쉬운 버전)
  view_source.bookmarklet.txt  위 스크립트를 한 줄로 압축한 javascript: 북마클릿
  build_bookmarklet.js         콘솔 스크립트를 고치면 북마클릿을 다시 만드는 빌드 스크립트
```

`view_source.console.js` 를 수정했다면 아래 명령으로 북마클릿을 다시 만듭니다.
외부 패키지 설치 없이 Node.js 표준 기능만 사용합니다.

```bash
node build_bookmarklet.js
```
