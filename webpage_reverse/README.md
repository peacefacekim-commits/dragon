# 웹페이지 코드로 보기

지금 화면에 "실제로 그려져 있는" 페이지(자바스크립트로 나중에 추가된 내용까지 포함)를
사람이 읽기 좋은 HTML 코드로 정리해 새 탭에 보여주는 도구입니다.

- 브라우저의 **페이지 소스 보기(`Ctrl+U`)** 는 서버가 맨 처음 내려준 원본 HTML만
  보여줍니다. 자바스크립트가 나중에 만들어 붙인 내용은 나오지 않습니다.
- 이 도구는 그 대신 **지금 이 순간의 DOM**을 가져와 들여쓰기를 붙여 정리하고,
  복사·다운로드 버튼과 함께 보여줍니다.

> **인터넷 연결이 없는 내부망(인트라넷) 페이지에서도 그대로 동작합니다.**
> 외부 서버로 아무것도 전송하지 않고, CDN 등 외부 리소스도 전혀 불러오지 않는
> 순수 자바스크립트이며, 지금 열려 있는 탭 안에서만 동작합니다.

---

## 사용법 — `index.html` 파일 하나만 열면 됩니다

1. [`index.html`](./index.html) 을 다운로드해 더블클릭(또는 브라우저에서 열기)합니다.
   인터넷 연결이나 서버 없이 파일을 그냥 열기만 하면 되고, 내부망 PC로 옮겨서
   열어도 동일하게 동작합니다.
2. 페이지 안내에 따라 둘 중 편한 방법을 고릅니다.
   - **방법 A (추천)**: 파란 **"📄 코드로 보기"** 버튼을 즐겨찾기 표시줄로 드래그해
     등록해 둡니다. 이후 코드로 보고 싶은 페이지에서 그 즐겨찾기를 클릭하면 끝입니다.
     드래그가 안 되면 그 아래 입력칸의 링크를 복사해 새 즐겨찾기의 주소(URL)로
     직접 붙여넣어도 됩니다.
   - **방법 B**: 코드로 보고 싶은 페이지에서 개발자 도구(`F12`)를 열고 **Console** 탭에
     `index.html` 안의 "코드 복사" 버튼으로 복사한 스크립트를 붙여넣고 `Enter`.
3. 실행하면 정리된 HTML 코드가 담긴 새 탭이 열립니다. 그 탭에서 코드를 다시
   복사하거나 `.html` 파일로 내려받을 수 있습니다.

> 콘솔에 코드를 처음 붙여넣으면 브라우저가 "코드를 붙여넣으면 안 됩니다" 같은 경고를
> 보여줄 수 있습니다. 직접 입력한 것이 맞다면 안내대로 `allow pasting` 등을 입력해
> 진행하면 됩니다. 실행 후 새 탭이 안 열리면 주소창의 **팝업 차단** 알림에서 허용해 주세요.

---

## 동작 원리

1. `document.documentElement.outerHTML` 로 현재 DOM 전체를 문자열로 가져옵니다.
2. 태그 단위로 잘라 들여쓰기를 붙이는 자체 포매터로 읽기 좋게 정리합니다.
   `<script>`/`<style>` 내용은 태그로 잘못 인식하지 않도록 통째로 다룹니다.
3. 결과를 HTML로 이스케이프한 뒤 `Blob` + `URL.createObjectURL` 로 새 탭에 표시합니다.
   서버에 아무것도 요청하지 않고 브라우저 메모리 안에서만 처리합니다.

일부 사이트는 보안 정책(CSP)으로 콘솔 스크립트의 동작을 제한할 수 있습니다.
이 도구는 새 창 열기(`window.open`)와 `Blob` URL만 사용하므로 대부분의 내부망
페이지에서 문제없이 동작하지만, 팝업을 강하게 차단하는 브라우저 설정에서는
새 탭이 열리지 않을 수 있습니다(위 팝업 차단 알림 참고).

## 파일 구성

```
webpage_reverse/
  index.html               사용자에게 전달하는 결과물. 이 파일 하나만 있으면 됩니다.
  view_source.console.js   index.html의 바탕이 되는 원본 스크립트 (읽기 쉬운 버전, 유지보수용)
  build_page.js             view_source.console.js 로부터 index.html 을 다시 만드는 빌드 스크립트
```

`view_source.console.js` 를 수정했다면 아래 명령으로 `index.html` 을 다시 만듭니다.
외부 패키지 설치 없이 Node.js 표준 기능만 사용합니다.

```bash
node build_page.js
```
