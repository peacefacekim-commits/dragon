# 붙여넣은 코드 정리하기

개발자 도구에서 복사한 HTML 코드를 이 페이지의 입력창에 붙여넣으면,
들여쓰기를 붙여 사람이 읽기 좋은 형태로 정리해 주는 도구입니다.

> **인터넷 연결이 없는 내부망(인트라넷) 페이지에서도 그대로 동작합니다.**
> `index.html` 파일 하나만 열면 되고, 붙여넣은 내용은 어디로도 전송되지 않으며
> 이 브라우저 탭 안에서만(자바스크립트로) 처리됩니다.

---

## 사용법

1. [`index.html`](./index.html) 을 다운로드해 더블클릭(또는 브라우저에서 열기)합니다.
   인터넷 연결이나 서버 없이 파일을 그냥 열기만 하면 되고, 내부망 PC로 옮겨서
   열어도 동일하게 동작합니다.
2. 코드로 보고 싶은 페이지에서 개발자 도구(`F12`)를 열고 **Elements**(요소) 탭에서
   원하는 요소를 우클릭 → **Copy → Copy outerHTML** 을 선택합니다.
   (페이지 전체를 복사하려면 트리 맨 위의 `<html>` 요소에서 우클릭하세요.
   또는 **Console** 탭에 `document.documentElement.outerHTML` 을 입력해 나온
   결과 문자열을 복사해도 됩니다.)
3. `index.html` 의 입력창에 붙여넣고 **"코드 정리하기"** 버튼을 누릅니다.
4. 아래쪽에 들여쓰기가 정리된 결과가 나타납니다. **"결과 복사"** 또는
   **".html로 다운로드"** 버튼으로 바로 활용할 수 있습니다.

---

## 동작 원리

붙여넣은 문자열을 태그(`<...>`) 단위로 잘라, 여는/닫는 태그에 맞춰 들여쓰기를
붙이는 자체 포매터로 재구성합니다. `<script>`/`<style>` 안쪽 내용은 태그로
잘못 잘리지 않도록 통째로 하나의 블록으로 다룹니다. 외부 라이브러리나
네트워크 요청 없이 순수 자바스크립트로 `index.html` 안에서 전부 처리됩니다.

## 파일 구성

```
webpage_reverse/
  index.html   사용자에게 전달하는 결과물. 이 파일 하나만 있으면 됩니다.
```
