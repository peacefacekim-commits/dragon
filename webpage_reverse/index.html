웹페이지 코드로 보기

지금 화면에 실제로 그려져 있는 페이지(자바스크립트로 나중에 추가된 내용까지 포함)를 사람이 읽기 좋은 HTML 코드로 정리해 새 탭에 보여줍니다. 외부 서버로 아무것도 보내지 않고 브라우저 안에서만 동작하므로, 인터넷이 없는 내부망(인트라넷) 페이지에서도 그대로 동작합니다.

방법 A · 즐겨찾기 한 번 클릭 (추천)

아래 버튼을 즐겨찾기 표시줄로 드래그하세요

📄 코드로 보기

즐겨찾기 표시줄이 안 보이면 Ctrl+Shift+B(Mac은 Cmd+Shift+B)로 켤 수 있습니다. 드래그가 안 되는 환경이라면 아래 링크를 복사해 새 즐겨찾기의 주소(URL) 칸에 직접 붙여넣으세요.

등록해 두면, 코드로 보고 싶은 아무 페이지에서나 클릭 한 번으로 실행됩니다.

방법 B · 개발자 도구 콘솔에 붙여넣기

아래 코드를 복사해 콘솔(F12 → Console)에 붙여넣고 Enter

콘솔에 처음 붙여넣으면 브라우저가 "코드를 붙여넣으면 안 됩니다" 같은 경고를 보여줄 수 있습니다. 직접 입력한 것이 맞다면 안내대로 allow pasting 등을 입력해 진행하면 됩니다.

실행하면 정리된 HTML 코드가 담긴 새 탭이 열립니다(팝업 차단 알림이 뜨면 허용해 주세요). 그 탭에서 코드를 다시 복사하거나 .html 파일로 내려받을 수 있습니다.
