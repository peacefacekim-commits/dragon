1. 개발자 도구에서 코드 복사하기

사이트마다 내용이 담기는 위치가 다릅니다. 아래 A 방법으로 잘 안 되면 B 방법을 시도해 보세요.

A. 화면에 보이는 요소에서 바로 복사 (일반적인 게시판)

  1. 개발자 도구(F12)를 열고 Elements(요소) 탭으로 이동합니다.
  2. 왼쪽 위 요소 선택 도구(화살표 아이콘, Ctrl+Shift+C)를 누른 뒤 화면에서 보고 싶은 글 제목·본문을 직접 클릭하면, Elements 탭이 그 부분의 HTML로 자동으로 이동합니다.
  3. 그 태그(또는 본문 전체를 감싸는 상위 요소)를 우클릭 → Copy → Copy outerHTML.

B. Network 탭에서 API 응답(JSON)으로 복사 (클릭해야 내용이 뜨는 게시판)

  1. 개발자 도구의 Network 탭을 열고 Fetch/XHR 필터를 켠 상태로 둡니다.
  2. 목록에서 보고 싶은 질문을 클릭합니다. 그 순간 목록 맨 아래에 새 요청이 하나 추가됩니다 — 그게 상세 내용을 가져오는 요청입니다.
  3. 그 요청을 클릭 → Response 탭에서 제목·본문 글자가 보이는지 확인합니다. (여러 개 떴다면 응답 안에 그 글의 실제 문장이 들어있는 걸 찾으면 됩니다.)
  4. Response 내용 안에서 우클릭 → Copy → Copy response (또는 전체 선택 후 복사).
