붙여넣은 코드 정리하기

개발자 도구에서 복사한 HTML 코드를 아래에 붙여넣으면 들여쓰기를 붙여 사람이 읽기 좋은 형태로 정리해 줍니다. 이 페이지 안에서만 동작하고 어디로도 전송되지 않으므로, 인터넷이 없는 내부망(인트라넷) PC에서도 파일을 그대로 열어 사용할 수 있습니다.

1. 개발자 도구에서 코드 복사하기

  1. 정리하고 싶은 페이지에서 개발자 도구(F12)를 열고 Elements (요소) 탭으로 이동합니다.
  2. 원하는 요소를 우클릭 → Copy → Copy outerHTML을 선택합니다. (페이지 전체를 복사하려면 트리 맨 위의 <html> 요소에서 우클릭하세요.)
  3. 또는 Console 탭에 document.documentElement.outerHTML 을 입력해 나온 결과 문자열을 복사해도 됩니다.
